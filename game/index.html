🎮 Khu vực game

Game đang được xây dựng. Khi người chơi thắng, game chỉ cần gọi moQua() là tấm thiệp (phần quà) sẽ mở ra.

// Dán hàm này vào game của bạn
function moQua() {
  try { localStorage.setItem("thiep2011_unlocked", "true"); } catch (e) {}
  if (window.parent !== window) {
    // game đang chạy bên trong trang thiệp (mode: "embed")
    window.parent.postMessage({ type: "GAME_WON" }, "*");
  } else {
    // game là trang riêng (mode: "redirect")
    location.href = "../index.html?gift=unlocked";
  }
}
